# NovaOS — نظام تشغيل محاكى داخل تطبيق أندرويد

تطبيق واحد يحتوي على **تجربة نظام تشغيل كاملة**: إقلاع (boot)، شاشة قفل، سطح مكتب، مدير نوافذ،
طرفية بأوامر حقيقية، مدير ملفات بنظام ملفات في الذاكرة، إعدادات، ومراقب موارد. كل شيء يعمل فعليًا —
لا صور ولا فيديو — لكنه بالطبع **يعمل فوق أندرويد ولا يستبدل نواته**.

> ملاحظة مهمة: "نظام تشغيل كتطبيق أندرويد" بالمعنى الحرفي غير ممكن — التطبيق محبوس في sandbox
> ولا يمكنه استبدال النواة أو التعريفات. ما يمكن (وهذا ما هنا) هو **محاكاة كاملة لتجربة النظام**،
> أو تغليفه كـ Launcher (واجهة تشغيل) إن أردت أن يظهر بدلًا من سطح مكتب أندرويد.

## التشغيل

```bash
cd os-sim
npm install
npm run dev        # معاينة في المتصفح على 0.0.0.0:5173
npm run build      # بناء dist/
```

## بناء APK

```bash
npm run cap:sync        # build + نسخ dist إلى مشروع أندرويد
cd android && ./gradlew assembleDebug
# الناتج: android/app/build/outputs/apk/debug/app-debug.apk
```

أو بكيفية واحدة: `npm run android`.

المشروع جاهز في `os-sim/android/` مع أيقونة تكيّفية (adaptive icon) وشاشة بداية (splash) بهوية NovaOS.
يتطلب بناء APK محليًا JDK 17+ و Android SDK (لم تُبنَ هنا لأن الـ sandbox لا يحتوي Java/Android SDK).

## ما الذي يعمل فعليًا

| الميزة | التفاصيل |
|---|---|
| الإقلاع | سجل نواة حقيقي التوليد + شريط تقدم + صوت، مع زر «تخطّي» |
| شاشة القفل | سحب للفتح، بصمة، إشعارات، عدم الإزعاج، ساعة حيّة |
| مدير النوافذ | سحب، تحجيم، تصغير، تكبير، طبقات z، إغلاق، نقاط جانبية |
| الملفات | VFS في الذاكرة: مجلدات، ملفات، محرّر نصوص، حذف، إنشاء (يُحفظ في localStorage) |
| الطرفية | `ls cd pwd cat echo mkdir touch rm df free uname neofetch date whoami notify wallpaper theme open apps lock reboot poweroff clear` — مع تاريخ الأوامر و Tab  |
| الآلة الحاسبة | عمليات متسلسلة، نسب، إشارة، تراجع |
| الخلفيات | 6 خلفيات مولّدة بـ CSS + 6 ألوان نظام تُغيّر الواجهة كلها |
| الإعدادات | السمة، الخلفية، الألوان، الأصوات، تقليل الحركة، المستخدم، إعادة الضبط |
| مراقب النظام | مشغّل حيّ للمعالج والذاكرة والعمليات والنوافذ |
| الإشعارات | مركز تحكم + إشعارات فورية (toasts) + كتم |
| الصوت | كل المؤثرات مُولّدة بـ Web Audio API (بدون ملفات صوت) |

## البنية

```
os-sim/
├── src/
│   ├── store/useOS.ts        # حالة النظام (zustand + persist): نوافذ، ملفات، إعدادات، إشعارات
│   ├── system/               # سجل التطبيقات، الدوال المساعدة، محرّك الصوت
│   ├── components/           # Boot, Lock, StatusBar, Dock, WindowManager, Launcher, Notifications…
│   └── apps/                 # التطبيقات الثمانية
├── android/                  # مشروع Capacitor أندرويد (NovaOS / os.nova.shell)
└── capacitor.config.ts
```

## تخصيص سريع

- إضافة تطبيق: أضِف مدخلًا في `src/system/apps.ts` ثم حالة في `src/apps/AppRenderer.tsx`.
- إضافة أمر طرفية: أضِف `case` داخل `run()` في `src/apps/TerminalApp.tsx`.
- إضافة خلفية: أضِف عنصرًا في `WALLPAPERS` داخل `src/store/useOS.ts` (ولون متاح في `ACCENTS`).
